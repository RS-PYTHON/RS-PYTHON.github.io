# RS-PYTHON.github.io

Template and content of the [RS-Python landing page](https://home.rs-python.eu/), the public home page of
[RS-Python](https://github.com/RS-PYTHON/rs-documentation).

## Overview

The website is generated by [GitHub Pages](https://docs.github.com/en/pages) with [Jekyll](https://jekyllrb.com/)
and the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme:

| Folder | Content |
|---|---|
| `_pages` | The main pages: home, features, services, events. |
| `_featureCollection` | The feature pages: rs-server, Jupyter, Prefect, deployment. |
| `_serviceCollection` | The service pages: STAC, processing, reprocessing. |
| `_posts` | The events. |
| `_data/navigation.yml` | The navigation menus, with the links to the [RS-Python documentation](https://home.rs-python.eu/rs-documentation/). |
| `assets` | The images, styles and scripts. |

The website also hosts the [RS-Python documentation](https://home.rs-python.eu/rs-documentation/) and the Helm
repository of [rs-helm](https://github.com/RS-PYTHON/rs-helm), published by their own repositories under the same
domain.

## Getting started

To preview the website locally, install [Ruby](https://www.ruby-lang.org/) and [Bundler](https://bundler.io/),
then:

```shell
bundle install
bundle exec jekyll serve
```

and open <http://localhost:4000>. The website is published on each push to the `main` branch.
